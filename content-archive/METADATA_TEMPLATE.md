# Standard metadata checklist: use for every final reel/Short
YT: 3 titles | description (hook, what viewers see, illustration/real note, link, credits, 3 hashtags) | tags (<=500 chars, include Hindi) | search keywords | category | audience | language | captions | altered-content flag | comments | pinned comment | related video | playlist | best post time | licence
IG: cover text | caption (hook, story, honesty note, CTA) | 8-10 hashtags | first comment | location | alt text | audio | share to FB | explore
FB: 2-line caption + link
Always: file spec, thumbnail + cover, keywords (primary, secondary, Hindi), fact flags (what footage shows vs does not show).
